# OPES Health mobile app updates

## 2026-11-06 — OTA, runtime 0.3.0

- Published Android and iOS preview update group `b0fd49bd-4501-4b87-81e7-f931f2eccfa0`.
- Added fictional, role-specific records to the staff, customer, practitioner, tester and partner demo workspaces so users can explore populated dashboards and supported local actions.
- Demo data remains on the device, is discarded when leaving demo mode and never enters the live API. Administrator demo access remains disabled.
- This JavaScript-only update is compatible with app/runtime `0.3.0`; Android build 8 does not change.

## 2026-11-06 — Android 0.3.0, build 8

- Added secure session recovery, retry-safe mutations, confirmed high-impact actions, live-record refresh and English/French support.
- Published update groups `1893ae72-0b3d-4eab-93ee-d5d9bdca5221` and `911604e1-d930-4468-b706-b322c870fda6` for runtime `0.3.0`.
