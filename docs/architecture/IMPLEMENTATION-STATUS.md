User-delegated OAuth authorization code with S256 PKCE is implemented separately from machine tokens. A reviewed public client must use an exact HTTPS redirect, consent is shown to the signed-in user, and user role/scope status is rechecked on refresh and API access. Business commands use idempotency receipts; transactional events are delivered to an inbox-backed activity projection. Password and implicit grants, OpenID Connect, userinfo and self-service client registration are not implemented.

Two additive migrations provide command receipts, the transactional outbox, event inbox, actor activity projection and a locked business reference sequence.
